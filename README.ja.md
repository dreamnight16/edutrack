# 世界線（Worldline）— 同世代の道が見える

> 高校生の情報の壁を打ち破る · 同世代の進学レーンを見る

## これは何か

大学入試（高考）だけが進路ではありません——オリンピック競技推薦、強基計画、総合評価、芸術試験（芸考）、スポーツ単独募集、海外留学、高等職業学校単独募集……どの道も異なる時期、異なるリソース、異なるリスクとリターンがあります。

小紅書（シャオホンシュー）や知乎（ヂーフー）には「逆転」の物語があふれていますが、沈黙する大多数が実際にどんな道を歩んでいるのかは見えません。

世界線がやることはシンプルです。**全国の同世代が実際に進んでいる進学レーンを可視化する**——それぞれのレーンにどんな重要なマイルストーンがあり、誰に向いていて、誰に向いておらず、どんなリソースが必要かを示します。判断は代わりにせず、全体像を見せます。

| 強基計画 | 入試 | 39 の双一流大学による基礎学科のエリート募集 |
| 総合評価 | 入試 | 高考成績 + 校内試験 + 学力試験を組み合わせた総合選抜 |
