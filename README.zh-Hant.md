# 世界線（Worldline）— 看見同齡人的路

> 高中生資訊破壁 · 看見同齡人的升學賽道

[![Next.js](https://img.shields.io/badge/Next.js-14-black)](https://nextjs.org/)

## 這是什麼

高考不是唯一的出路——競賽保送、強基計畫、綜合評價、藝考、體育單招、出國留學、高職單招……每條路都有不同的時間節點、資源需求和風險報酬。

小紅書和知乎上充斥著「逆襲」敘事，但沉默的大多數是怎麼走路的，你根本看不到。

世界線做的事很簡單：**把全國同齡人真實在走的升學賽道展示出來**——每條賽道有什麼關鍵節點、適合誰、不適合誰、需要什麼資源。不替你判斷，只幫你看到全貌。

|------|------|------|
| 資訊學競賽 | 競賽 | CSP-J/S → NOIP → 省選 → NOI → 國家集訓隊 |
| 強基計畫 | 招生 | 39 所雙一流高校的基礎學科拔尖招生 |
| 綜合評價 | 招生 | 高考成績 + 校測 + 學考的綜合錄取方式 |

> 更多賽道持續新增中。
